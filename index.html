Často kladené dotazy

Vše, co potřebujete před začátkem vědět.

Jak probíhá platba?

Před začátkem prací na webu se hradí záloha ve výši 50 % (1 500 Kč). Druhá polovina se doplácí až ve chvíli, kdy je web kompletně hotový a připravený ke spuštění.

Pomůžete mi s nahráním webu na internet?

Ano! Rádi vám pomůžeme s nákupem domény i s technickým nahráním hotového souboru index.html na váš webhosting, aby byl web ihned funkční.

Proč zvolit statický web místo WordPressu?

Statický web neobsahuje žádnou databázi, načítá se bleskově, nelze jej snadno napadnout hackery a nevyžaduje neustálé placené aktualizace.

Jak dlouho trvá výroba webu?

Jakmile obdržím podklady a zálohu, web bývá hotový zpravidla do 3 až 7 dnů.
